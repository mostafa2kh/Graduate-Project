# AI Review Service

Generates mock AI trust scores and flags for submitted listings.

- **Port:** 8085
- **Database:** rentsphere_ai_review_db
- **Dependencies:** Listing Service

## Key Features

- Mock trust score (0–100) based on listing completeness
- Review flags for missing images, suspicious pricing
- Automated review on listing submission
- Admin rerun capability
- Clearly documented as simulated AI
